☕ Cafe & Wifi API

A small REST API of laptop-friendly London cafes - with wifi, sockets and coffee prices.

GET/random

Get one random cafe.

GET/all

Get every cafe, sorted by name.

GET/search?loc=Peckham

Find cafes in a location.

POST/add

Add a cafe (form data): name, map_url, img_url, location, seats, has_toilet, has_wifi, has_sockets, can_take_calls, coffee_price.

PATCH/update-price/<cafe_id>?new_price=£2.50

Update a cafe's coffee price.

DELETE/report-closed/<cafe_id>?api-key=YOUR_KEY

Remove a cafe that has closed. Needs the API key.
